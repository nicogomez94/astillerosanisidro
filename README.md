# Astillero San Isidro — landing estática

Landing en HTML, CSS y JavaScript puro. Abrí `index.html` o serví la carpeta con cualquier servidor estático.

## Contenido y marca

- El logo se recortó directamente de `ASI logo placement.pptx`.
- La paleta web aproxima los Pantone 7458 C, 549 C y 7413 C indicados en esa presentación.
- La dirección y el teléfono también provienen del PPT.
- Las embarcaciones de las imágenes son ilustrativas y no representan modelos específicos del astillero.

## Edición rápida

- Textos y secciones: `index.html`.
- Colores, medidas y diseño responsive: `styles.css`.
- Interacción del hero, menú y animaciones: `main.js`.

El enlace de WhatsApp usa el número indicado en el PPT; conviene confirmar que esa línea tenga WhatsApp habilitado antes de usar la página como canal comercial principal.
